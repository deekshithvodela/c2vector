Privacy Policy & Security Guarantee

100% In-Browser Execution

c2vector is engineered from first principles as an offline-capable, client-side progressive web application. Every operation — image resampling, bilateral filtering, Canny edge detection, Otsu binarization, CIELAB quantization, Bézier curve tracing, and multi-page PDF compilation — runs entirely inside your device's browser memory via Web Workers.

Zero Cloud Storage & Zero File Uploads

Your uploaded photographs, generated SVG plates, and compiled PDFs never travel over the network to any server or cloud service. Once you close or reload the tab, in-memory image buffers are immediately reclaimed by garbage collection.

Zero Tracking, Cookies & Third-Party Ad Pixels

c2vector does not set advertising cookies, persist tracking identifiers, or sell analytics data. Usage metrics are gathered using GoatCounter — a privacy-first, GDPR-compliant open-source analytics service that does not track users across sites or record personal identifiable information (PII).

Local Preferences

Only your aesthetic UI theme preference (dark/light mode) is stored locally on your device via localStorage to prevent screen flickering upon future visits.

Disclosure & Technical Specifications

Deterministic Mathematical Vectorization (0% AI)

c2vector is not a generative AI tool, machine learning model, or diffusion wrapper. All outputs are derived deterministically using peer-reviewed computer vision and geometric curve-fitting algorithms:

  • Otsu Automatic Binarization: Minimizes intra-class variance to isolate foreground silhouettes.
  • Canny Sub-Pixel Edge Detection: Sobel convolution kernels with hysteresis thresholding and non-maximum suppression.
  • CIELAB Color Space Quantization: Perceptually uniform k-means clustering calibrated to human visual sensitivity.
  • Schneider-Ramer-Peucker Spline Fitting: Continuous parametric cubic Bézier curve tracing with G1 geometric slope continuity.

Vector PDF & SVG Compatibility

All exported SVG files adhere strictly to the W3C SVG 1.1 standard with clean grouping, semantic attributes, and explicit viewBox boundaries. Exported vector PDFs are compiled using jsPDF and svg2pdf.js entirely in client memory without external rendering binaries.
